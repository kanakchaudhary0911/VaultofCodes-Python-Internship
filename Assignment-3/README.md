# Assignment 3 - Personal Expense Tracker

## 📌 Project Overview

This project is a command-line based **Personal Expense Tracker** developed in Python as part of the **VaultofCodes Python Internship – Week 3**.

The application allows users to record daily expenses, organize them into categories, view spending summaries, manage existing expense records, and save expense data using JSON file handling.

The project follows a menu-driven approach and demonstrates practical implementation of Python fundamentals, functions, lists, dictionaries, loops, conditional statements, file handling, exception handling, and basic data analysis and visualization.

---

## 🎯 Objective

The objective of this project is to develop a simple and practical expense management system that helps users track their daily spending while applying core Python programming concepts and file handling techniques.

---

## ✨ Features

- Add a new expense
- View all saved expenses
- Category-wise expense summary
- Overall expense summary
- Monthly expense summary
- Search expenses by category
- Edit an existing expense
- Delete an expense
- Save expense data using JSON file handling
- Load previously saved expenses automatically
- Display expense analytics using Matplotlib
- Menu-driven command-line interface
- Input validation and error handling

---

## 🛠 Technologies Used

- Python 3
- JSON File Handling
- Datetime Module
- Matplotlib
- Lists and Dictionaries
- Functions and Modular Programming
