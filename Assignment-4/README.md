# Personal To-Do List Application

## Overview

The **Personal To-Do List Application** is a command-line Python project developed as part of the **VaultofCodes Python Internship – Assignment 4**. The application helps users create, organize, edit, complete, and delete daily tasks while storing all task information in a JSON file for future use.

---

## Features

* Add new tasks
* View all tasks
* View completed tasks
* View pending tasks
* Filter tasks by category
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* Store tasks permanently using JSON file handling
* Automatically load previously saved tasks
* Menu-driven command-line interface
* Input validation and user-friendly prompts

---

## Technologies Used

* Python 3
* Object-Oriented Programming (OOP)
* JSON File Handling
* Lists and Dictionaries
* Command-Line Interface (CLI)
